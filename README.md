# 🏠 House Price Prediction

A Machine Learning project that predicts house prices based on various property features like location, square feet area, BHK, bathrooms, and more.

## 🚀 Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning Model Training
- House Price Prediction
- User-friendly Prediction System

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib
- Flask / Streamlit (if used)

## 📂 Project Structure
├── app.py
├── eda.ipynb
├── cleaned_df.csv
├── Bengaluru_House_Data.csv
├── requirements.txt
├── rf_model.joblib
├── model_columns.joblib
└── README.md

## 📊 Dataset
The dataset contains Bengaluru house price data with features such as:
- Location
- Total Square Feet
- Number of Bedrooms
- Bathrooms
- Price
